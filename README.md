# Infinite-Board
A Project for Hack Club HackPad. This is a the Infinite Boards Repo for me to use for daily and gameing. I am also using this project to learn coding and new skills. Also  Thanks to Hack Club for giving me this opurtunity.


**What Is the Infinite Pad?** 
Infinite Pad is a project I have been working on to submit to hack club hack pad mission. This pad can be used for gaming or work use as it has a lot of functions.

**How many keys?**
There are 12 keys with different fetures on each one. 

**What does it use?**
It uses 
Part,Quantity,Used For
XIAO RP2040,1,Microcontroller
1N4148 through-hole diode,12,Key matrix
MX-style mechanical switch,12,Keys
2-pin rotary encoder,0,Not used
0.91-inch OLED display,1,Startup display
DSA keycap,12,Keycaps
SK6812 MINI-E,0,Not used
M3 x 16mm screw,4,Case assembly
M3 x 5 x 4mm heat-set insert,4,Case screw mounting
3D printed case,1,Enclosure
PCB,1,Custom 2-layer PCB

**What is the OLED for?**
It is used for displaying text. Also It displays if the Pad is redy to be used and if it is working.

**Why you wanted a macro pad**
I wanted to make a macro pad because I would like to learn new skills and make hardware.

**Why you designed your own instead of using an existing one**
Because I wanted to learn new skills and not copy others. 

**What makes your design different/useful** 
It is also easy to use and easy for the hand to tap each button.
